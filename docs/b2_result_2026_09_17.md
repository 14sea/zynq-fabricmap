### The exit-127 attempt

The first invocation of the adjudicator was issued through an unquoted shell variable; zsh does not
word-split such a variable, so the whole command line was looked up as a single file name. The
shell returned exit 127 with `no such file or directory`; **the adjudicator was never started and
nothing was adjudicated**. That attempt's `command.txt`, empty `stdout.txt`, `stderr.txt`,
`exit_code.txt` and `run_record.json` are preserved as observed in
`evidence/b2/b2_primary_2026-09-17/attempt1_shell_error/` with a note. The pooled adjudication was
therefore executed exactly once, as released.
