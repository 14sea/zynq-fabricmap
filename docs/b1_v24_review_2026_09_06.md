1. **[P2] Failed raw-console export can still produce PASS.**
   `host/b1_session.py:150` checks only run_log.json, audits.json and timeline.json.
   It ignores failed console.log, console.ts.log and session_summary exports, and iterates
   only keys that happen to exist rather than requiring the complete set. With real
   completed modelled-B1Q objects, the production exporter/finalizer and the real B1Q
   adjudicator, injecting an OSError only into console.log's write produces:

   ```text
   console.log = INCOMPLETE: OSError: injected console.log write failure
   console.log exists = false
   finalize outcome = PASS
   adjudication outcome = PASS
   ```

   Required change: explicitly require every mandatory export and successful summary
   construction before an overall PASS. A failed or absent export must remain a named
   HOLD/incomplete result; a diagnostic adjudicator result must not promote the session
   or its qualification record to PASS. Cover both raw-console outputs and missing
   required export-status keys, not only a failed run_log export.

2. **[P2] Auxiliary serialization errors still suppress collected records and chunks.**
   `write_run_log` computes timing and renders the notary log before its first disk write
   (`host/b1_session.py:109–128`). `write_audits` renders all ledgers before writing the
   already-collected chunks (`host/b1_session.py:131–139`). The surrounding try blocks
   keep other files alive, but do not preserve independent components within these files.
   Reproductions over actual completed modelled-session objects show:

   | Injected helper failure | Data already collected | Result |
   |---|---|---|
   | rel_ledgers_json raises RuntimeError | 88 audit chunks | audits.json absent |
   | record_timing raises RuntimeError | 11 records and 11 notary entries | run_log.json absent |

   Required change: save available base records/chunks independently of timing and ledger
   enrichment. Isolate each enrichment failure, retain all available components and mark
   the missing component explicitly. A partial artifact must remain HOLD and must not
   masquerade as complete. Cover timing, notary rendering and each ledger renderer, as
   well as summary construction failure. The injected failures here are controlled
   off-board fault tests, not claims that these helpers failed during session 1.

3. **Regression gap: the claimed post-go exception test does not call run().**
   `tests/test_b1_session_finalize.py:170–202` defines fake_precheck, cfg, Session and
   real_run, but never uses them to execute the session. It calls export_evidence
   directly at line 198; no exception is injected into run(), and its finally block is
   never reached. This test would still pass if run's exception-export branch were
   removed. Replace or supplement it with a test invoking the real b1_session.run with
   fake setup/transport dependencies, reaching console operation and injecting a host
   exception there. Assert exported evidence, preserved primary epoch cause, secondary
